# Open-questions review (Phase 12)

**IgniSense — Smart Engine Health Diagnostic · Team Revora**

Every item in [open-questions.md](open-questions.md) is below, sorted by who has to decide it. Tick **accept**, or write the change. After the review, the accepted items are marked RESOLVED in `open-questions.md`, the changes are applied, the tests and the Validation page are re-run, and [calibration.md](calibration.md) is checked against the code.

**Review outcome (2026-09-29):** all 62 questions have a decision below. The implemented choices are accepted as **prototype/demo calibration**, not manufacturer-validated limits. Q-57 changes the presentation by adding a limiting-subsystem label. Q-26 and Q-36 retain a pre-demo device check; Q-59 keeps unverified serial hardware out of the live demo.

Every provisional choice is already implemented and covered by the test suite (361 tests passing). Accepting one changes no code. Changing one means editing a value in `src/engine/profile.ts` or `src/analytics/config.ts`, then re-running `npm test`.
