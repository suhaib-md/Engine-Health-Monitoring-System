# Handouts

Two documents for Team Revora, built from screenshots of the running app.

| File | For | What it is |
| --- | --- | --- |
| `IgniSense-Guide.pdf` | The team | The complete guide: what every feature does, the exact clicks to use it, the physics and diagnosis explained, the five-minute demo, a replicate-it-tomorrow checklist, phases and project map, key numbers, limitations, glossary (29 pages) |
| `IgniSense-Deck.pptx` | Visitors and reviewers | 17-slide showcase deck in the IgniSense look, with speaker notes on every slide. Native, editable PowerPoint shapes |

## Rebuilding them

The guide's source is `IgniSense-Guide.html` (images in `img/`, fonts in `fonts/`). Edit it, then:

```bash
node docs/handouts/print_guide.mjs        # needs Edge or Chrome installed; writes IgniSense-Guide.pdf
```

The deck is generated by `build_deck.py` (wording and layout are in the SLIDES section at the bottom):

```bash
pip install python-pptx pillow
python docs/handouts/build_deck.py        # writes IgniSense-Deck.pptx
```

Fonts in the deck are Segoe UI and Consolas (stock on Windows). On a Mac PowerPoint substitutes similar fonts.

## About the screenshots

The images in `img/` were captured from the running app in headless Edge (1440 px wide). The 3D view was rendered in software there, so its frame-rate readout was hidden in those three images; on a laptop GPU the app shows about 60 fps. To retake a screenshot, run the app (`npm run dev`), do the steps in the guide, and save over the file in `img/`, then rebuild.
